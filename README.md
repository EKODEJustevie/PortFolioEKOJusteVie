# Portfolio Professionnel - Juste-Vie MILAGUEH

## 🚀 Portfolio d'Ingénieur Aéronautique & Développeur

Ce portfolio moderne et professionnel a été conçu spécialement pour mettre en valeur vos compétences en:
- **Aéronautique** ✈️
- **Technologies & Programmation** 💻
- **Cybersécurité** 🔒
- **Électronique & Systèmes Embarqués** ⚡

## 📁 Fichiers Inclus

1. **index.html** - Structure HTML complète du portfolio
2. **style.css** - Styles modernes avec animations et effets
3. **script.js** - Interactivité et animations JavaScript

## ✨ Fonctionnalités

### Design Moderne
- **Navigation fixe** avec effet de transparence
- **Hero Section** avec animation de particules
- **Palette de couleurs tech** (cyan, violet, orange)
- **Animations fluides** au scroll
- **Effets hover** sur tous les éléments interactifs

### Sections Incluses
1. **Accueil** - Présentation avec photo de profil animée
2. **À Propos** - Biographie avec effet typewriter + statistiques
3. **Compétences** - Onglets interactifs pour:
   - Programmation (Python, JavaScript, C++, Java, React, Node.js)
   - Électronique (Arduino, Raspberry Pi, IoT)
   - Logiciels (VS Code, Git, Linux, Docker)
   - Cybersécurité (Kali Linux, Pen Testing, Cryptographie)
4. **Langues** - Français, Anglais, Espagnol
5. **Formation** - Timeline interactive du parcours
6. **Projets** - Grille de projets avec filtres
7. **Loisirs** - Cartes interactives avec liens Wikipedia
8. **Contact** - Liens vers réseaux sociaux (GitHub, WhatsApp, Telegram, Email)

### Responsive
- **Mobile First** design
- S'adapte à toutes les tailles d'écran
- Menu burger pour mobile


### Image de Profil
Placez votre photo dans: `images/P.png`

### Biographie
Modifiez la variable `Bio` dans `script.js`:
```javascript
const Bio = "Votre texte ici...";
```

### Réseaux Sociaux
Mettez à jour les liens dans la section Contact du HTML:
- GitHub

- Telegram
- Email

## 📝 Utilisation

1. **Téléchargez** les 3 fichiers (index.html, style.css, script.js)
2. **Placez-les** dans le même dossier
3. **Créez** un dossier `images/` avec votre photo (`P.png`)
4. **Ouvrez** index.html dans votre navigateur

## 🌐 Hébergement

Vous pouvez héberger ce portfolio sur:
- **GitHub Pages** (gratuit)
- **Netlify** (gratuit)
- **Vercel** (gratuit)
- **Votre propre serveur**

### Pour GitHub Pages:
1. Créez un dépôt GitHub
2. Uploadez les fichiers
3. Activez GitHub Pages dans les paramètres
4. Votre site sera accessible à: `username.github.io/repo-name`
